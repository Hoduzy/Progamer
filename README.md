# LCK 프로게이머 커리어

리그 오브 레전드 프로게이머가 되어 2군에서 시작해 1군 주전, 국제 대회, 재계약·FA까지 이어가는 개인용 커리어 게임입니다.
빌드 도구 없이 정적 파일(HTML + CSS + 바닐라 JavaScript ES 모듈)만으로 동작합니다.

> 실제 LCK 팀 이름과 챔피언·아이템·오브젝트 명칭을 사용하지만, **모든 선수·감독은 가상의 닉네임**입니다. 개인 플레이 전용입니다.

## 실행 방법

ES 모듈은 `file://`로 열면 동작하지 않으므로 간단한 정적 서버로 엽니다.

```bash
cd Progamer
python3 -m http.server 8080      # 또는: npx serve .
# 브라우저에서 http://localhost:8080 접속
```

- 아이패드: 같은 와이파이의 PC에서 서버를 띄우고 `http://<PC IP>:8080`으로 접속하거나, 정적 호스팅(비공개 저장소라면 로컬 서버 권장)에 올려서 사용합니다. 가로 화면(1180×820) 기준이며 화면 크기에 맞게 자동으로 배율이 조정됩니다.
- 인터넷이 되면 Riot Data Dragon에서 챔피언 아이콘·스플래시·아이템·미니맵을 받아 localStorage에 캐시합니다. 오프라인이면 대체 그래픽을 씁니다.

### 검증 도구 (node 18+)
```bash
node tools/sim-choices.mjs     # 선택 장면 확률 범위(5~95%)·우월 선택지 검사
node tools/sim-season.mjs      # 시즌 10회 자동 진행 통계 (팀별 순위, 국제대회 우승 지역, 경기 시간, 킬 수)
node tools/sim-season.mjs 5 --chain   # 한 월드에서 5시즌 연속 (시즌 넘김·FA·노화 검증)
```

## 진행 상황
- [x] 1단계: 데이터 + 경기 엔진 + 경기 화면 (타이틀 → 테스트 경기로 한 경기 플레이)
- [x] 2단계: 밴픽 화면 (피어리스 드래프트, 퍼스트 셀렉션, 감독 추천, 조합 평가) — 타이틀 → 테스트 경기 → Bo3
- [x] 3단계: 캐릭터 생성 + 입단 제안 + 메인 허브 + 시즌 캘린더 + 하루 3칸 훈련/루틴 + 패치 + 다른 팀 경기 자동 시뮬레이션 + 순위표 (LCK컵·LCK 정규·CL 정규)
- [x] 4단계: 대회 구조 전체 — LCK컵, First Stand(GSL 그룹+녹아웃), LCK 1~2R, Road to MSI, MSI(플레이-인+DE8), LCK 3~4R, LCK 플레이오프(플레이-인+DE6), CL 플레이오프, Worlds(플레이-인+스위스+녹아웃), 지역 대표 선발, 대진 화면
- [x] 5단계: 연봉(월급)·계약·바이아웃·1군/2군·FA 제안/협상/재계약·이적 요청·AI 선수 이적·노화·은퇴·신인 충원·다음 시즌·은퇴와 명예의 전당
- [ ] 6단계: 커뮤니티·인터뷰·이벤트·수상·기록실, 밸런스

## config.js 주요 항목
| 구역 | 내용 |
|---|---|
| `match` | 틱 길이, 포지션별 GPM/CS/XP, 부활 시간, 골드 보상, 라인전 교전·갱킹 확률, 한타 스케일(`fight.scale`), 인원 차 보정, 골드→파워 환산(`goldPerK`), 능력치 반영 비율(`statScale`), 오브젝트 등장 시간(`objectives`), 아타칸 켜기/끄기 |
| `scene` | 경기당 장면 수(5~8), 제한시간 15초, 확률 보정 계수, 확률 상·하한, 판단력 기준 정확 표시, 대성공/대실패 비율, 평점 변화 |
| `rating` | 평점 공식 가중치, 선택 장면 반영 비율(`choiceWeight`) |
| `growth` | 행동별 성장량(`baseGain`), 나이별 성장 배율, 숙련도 상승량, 잠재력 범위 |
| `daily` | 행동별 피로, 밤 회복량, 방송 팬/수입/논란 확률, 솔랭 LP |
| `injury` | 부상 시작 피로, 확률, 결장 일수 |
| `lineup` | 주전 결정 가중치(신뢰도·평점·컨디션·스크림·능력치), 콜업/강등 기준 |
| `patch` | 패치 주기(14일), 버프/너프 폭, 메타 티어 비율·파워 |
| `salary` | 연봉 시세 공식(기본·증가율·인기 배율), 바이아웃 배수, 협상 인상률·수락 확률, 거절 시 철회 확률, 이적 요청 수락 확률 |
| `fa` | FA 기간, 팀별 제안 확률, 해외 비중, AI 이적 확률, 은퇴 나이·확률 |
| `competitions` | 대회 시작일, Bo 수, 경기 요일, 하루 경기 수, 지역 출전권 |
| `ui` | 1배속 속도(게임 1분 = 4초), 장면 전환 시간 |
