# LCK 프로게이머 커리어

리그 오브 레전드 프로게이머가 되어 2군에서 시작해 1군 주전, 국제 대회, 재계약·FA까지 이어가는 개인용 커리어 게임입니다.
빌드 도구 없이 정적 파일(HTML + CSS + 바닐라 JavaScript ES 모듈)만으로 동작합니다.

> 실제 LCK 팀 이름과 챔피언·아이템·오브젝트 명칭을 사용하지만, **모든 선수·감독은 가상의 닉네임**입니다. 개인 플레이 전용입니다.

## 실행 방법

ES 모듈은 `file://`로 열면 동작하지 않으므로 간단한 정적 서버로 엽니다.

```bash
cd Progamer
python3 -m http.server 8080      # 또는: npx serve .
# 브라우저에서 http://localhost:8080 접속
```

- 아이패드: 같은 와이파이의 PC에서 서버를 띄우고 `http://<PC IP>:8080`으로 접속하거나, 정적 호스팅(비공개 저장소라면 로컬 서버 권장)에 올려서 사용합니다. 가로 화면(1180×820) 기준이며 화면 크기에 맞게 자동으로 배율이 조정됩니다.
- 인터넷이 되면 Riot Data Dragon에서 챔피언 아이콘·스플래시·아이템·미니맵을 받아 localStorage에 캐시합니다. 오프라인이면 대체 그래픽을 씁니다.

### 검증 도구 (node 18+)
```bash
node tools/sim-choices.mjs     # 선택 장면 확률 범위(5~95%)·우월 선택지 검사
```

## 진행 상황
- [x] 1단계: 데이터 + 경기 엔진 + 경기 화면 (타이틀 → 테스트 경기로 한 경기 플레이)
- [ ] 2단계: 밴픽 화면 (피어리스 드래프트)
- [ ] 3단계: 캐릭터 생성 + 시즌 캘린더 + 훈련 + 자동 시뮬레이션 + 순위표
- [ ] 4단계: 대회 구조 전체
- [ ] 5단계: 연봉·계약·FA·은퇴
- [ ] 6단계: 커뮤니티·인터뷰·이벤트·수상·기록실, 밸런스

## 파일 구조
```
index.html            진입점
css/style.css         전체 스타일 (1180×820 기준)
js/config.js          ★ 모든 수치 상수
js/core/              rng.js(시드 난수), util.js
js/engine/            화면 없는 로직 (node에서 실행 가능)
  match.js            경기 엔진 (10초 틱)
  choices.js          선택 장면 확률·판정·효과
  draft.js            밴픽 AI, 조합 평가
  meta.js             패치·메타 티어
  players.js          선수 생성·OVR·성장
  rating.js           평점·POG
  mapgeo.js           미니맵 좌표
js/ui/                화면 (app.js 라우터, assets.js 이미지, matchScreen.js 경기 화면, screens/*)
data/                 챔피언·아이템·팀·이름·선택 장면·해설 문장
tools/                시뮬레이션 검증 스크립트
docs/DESIGN.md        전체 설계
assets/               팀 로고, 내 사진 (assets/README.md 참고)
```

## config.js 주요 항목
| 구역 | 내용 |
|---|---|
| `match` | 틱 길이, 포지션별 GPM/CS/XP, 부활 시간, 골드 보상, 라인전 교전·갱킹 확률, 한타 스케일(`fight.scale`), 인원 차 보정, 골드→파워 환산(`goldPerK`), 능력치 반영 비율(`statScale`), 오브젝트 등장 시간(`objectives`), 아타칸 켜기/끄기 |
| `scene` | 경기당 장면 수(5~8), 제한시간 15초, 확률 보정 계수, 확률 상·하한, 판단력 기준 정확 표시, 대성공/대실패 비율, 평점 변화 |
| `rating` | 평점 공식 가중치 |
| `ui` | 1배속 속도(게임 1분 = 4초), 장면 전환 시간 |
