# 추천 루틴

주간 루틴 편집 화면의 **✨ 추천 루틴** 버튼. 앞으로 7일의 활동을 실제 게임 공식의 기댓값으로 계산해 3가지 안을 카드로 보여 준다.
계산은 `js/routine-advisor.js`, 수치는 `CONFIG.advisor`.

## 화면
- 주간 루틴 편집 → **✨ 추천 루틴** → 카드 3장: 균형형 / 성장 집중형(피로·부상 위험 표시) / 컨디션 관리형.
- 카드마다
  - 월~일 활동과 칸마다 한 줄 이유 (예: "한타 약점 (−19)", "내일 경기 — 푹 쉬기", "케미 낮은 팀원 Nyterx").
  - 주간 예상 결과: 능력치 경험치·OVR, 피로(시작 → 주말, 최고치), 멘탈, 콜업 게이지(2군) 또는 주전 점수 차(1군), 감독 신뢰, 수입, 경기 당일 컨디션.
  - 추천 이유 두 줄 (예: "한타가 주전 경쟁자보다 18 낮아요 · 멘탈이 주전 경쟁자보다 12 낮아요", "월요일 경기라 일요일은 휴식").
- 카드를 누르면 편집 화면에 그대로 채워진다. 이후 칸을 눌러 하루씩 바꿀 수 있다 (바꾼 칸은 추천 이유가 사라진다).
- **↩ 되돌리기**: 적용 전 루틴을 복구한다 (`user.routineBackup`). 경기일 칸은 건드리지 않는다.
- 설정 → **매주 자동으로 균형형 추천 적용** (기본 꺼짐): 켜면 "일주일 넘기기" 때 그 주 상황으로 균형형을 새로 계산해 루틴에 쓴다. 자동 적용은 되돌리기 백업을 만들지 않는다.

## 계산 방식
### 예상 결과 = 실제 공식의 기댓값
- `engine/daily.js`와 같은 순서·같은 식으로 하루씩 진행한다: 회복일 보너스 → 같은 훈련 연속 감소 → 활동 효과 → 피로·부상 → 밤 회복.
- 같은 함수를 직접 쓴다: `growStat`(능력치 경험치), `masteryGainOf`(숙련도), `conditionOf`·`staminaMult`(컨디션·체력 보정), `ovrExact`(소수 OVR), `CONFIG.daily`·`CONFIG.injury`.
- 무작위는 기댓값으로 처리한다.
  - 스크림: 승률·세트 수의 기댓값.
  - 솔로 랭크: LP 기댓값.
  - 방송: 팬·수입 평균, 논란 확률 × 효과.
  - 부상: 피로가 72를 넘은 만큼의 확률을 누적.
  - 경기일: 세트 2.4개(Bo3 평균)의 경험 성장·감독 신뢰·피로.
- **검증**: 같은 상태에서 추천 루틴을 실제 엔진으로 100번 돌린 평균과 비교했다 (경기 있는 주).

| 항목 (예상 / 실제 평균 40회) | 균형형 | 성장 집중형 | 컨디션 관리형 |
|---|---|---|---|
| 능력치 경험치 합 | 2.03 / 2.06 | 2.83 / 2.85 | 1.00 / 1.01 |
| 피로(주말) | 8.6 / 8.6 | 20.2 / 20.2 | 0.0 / 0.0 |
| 멘탈 | 93.6 / 93.4 | 86.2 / 86.2 | 98.6 / 98.6 |
| 케미 합 증가 | 29.4 / 30.2 | 14.4 / 14.4 | 22.2 / 23.3 |
| 수입(만 원) | 307 / 320 | 0 / 0 | 307 / 297 |
| 감독 신뢰 | 54.9 / 60.7 | 55.3 / 61.4 | 54.9 / 60.8 |

  - 능력치 경험치는 경기일 세트를 1개로 계산하던 것을 2.4개(Bo3 평균, `matchGames`)로 고쳐서 1% 안으로 맞았다 (고치기 전 실제보다 9% 낮았다).
  - 감독 신뢰는 경기 결과(평점·승패)에 달려 있어 예상이 조금 낮다. 경기 기록이 없을 때 쓰는 예상 평점(`defaultRating` 6.8)을 시뮬레이션 평균에 맞췄다.
  - 경기 없는 주는 능력치 합 1.09 / 1.08, 2.28 / 2.27로 거의 같았다.

### 후보 배치 고르기
- 하루 후보: 스크림, 개인 훈련(약점 상위 3), 챔피언 연습(메타 후보, 주 1회), 솔로 랭크, 리플레이, 휴식.
- 7일 × 후보를 **빔 탐색**(폭 40)해 점수가 가장 높은 배치를 고른다. 계산은 3안 합쳐 수십 ms다.
- 규칙
  - **일정**: 경기일은 활동 없음. 경기 전날은 휴식 또는 가벼운 활동. 경기 다음 날은 회복일 보너스(피로 −8, 휴식 ×1.3)를 활용한다.
  - **약점**: 2군이면 1군 주전 경쟁자, 1군이면 LCK 1군 같은 포지션 평균과 8개 능력치를 비교한다. 차이가 큰 2개를 우선 훈련하고 이유에 "○○가 주전 경쟁자보다 N 낮아요"로 쓴다.
    - 훈련 가치는 포지션 중요도(OVR 가중치)도 반영한다. 약점이어도 OVR에 거의 안 들어가는 능력치만 올리지 않게 하기 위해서다.
  - **메타**: 이번 패치 OP·1티어 중 내 포지션이면서 숙련도가 60 미만인 챔피언을 연습 후보로 한다.
  - **연속 감소 회피**: 같은 훈련이 3일 이어지면 효과가 줄어드니 섞어서 배치한다.
  - **피로 상한**: 활동 뒤 피로가 상한(균형형 70, 성장 집중형 90, 컨디션 관리형 55)을 넘을 것 같으면 그날은 휴식을 넣는다.
  - **케미**: 케미 40 미만 팀원이 있으면 "팀원과 시간" 주 1회 (가장 낮은 팀원).
  - **돈·팬**: 자금 300만 원 미만이거나 팬이 목표(2군 2,000·1군 15,000)보다 적으면 개인 방송 주 1회.
  - 한 능력치만 계속 올리면 가치가 줄어든다(`gainSat`). 약점 2개를 번갈아 훈련하게 하기 위해서다.

### 3안의 차이 (점수 가중치와 정책, `CONFIG.advisor.plans`)
| | 균형형 | 성장 집중형 | 컨디션 관리형 |
|---|---|---|---|
| 목표 | 성장 + 콜업 게이지 + 컨디션 | 약점 훈련량 최대 | 경기 당일 컨디션·안전 |
| 피로 상한 | 70 | 90 | 55 |
| 경기 전날 | 피로 35 넘을 때만 휴식, 아니면 리플레이 | 리플레이 (휴식 없음) | 항상 휴식 |
| 부상 확률 감점 | 큼 (8) | 작음 (1.2) | 매우 큼 (12) |
| 피로가 다음 훈련 효율을 깎는 것 | 계산에 넣음 | **넣지 않음** (`ignoreTired`) | 계산에 넣음 |
| 팀원과 시간·방송 | 매주 | 2주에 한 번 | 매주 |
| 콜업 게이지·감독 신뢰 가치 | 1.2 | 0.5 | 0.8 |

- 성장 집중형은 피로 때문에 다음 훈련 효율이 떨어지는 것을 일부러 계산에 넣지 않는다(훈련량으로 밀어붙임). 그래서 피로·부상 위험이 가장 크고, 카드에 부상 위험 %를 표시한다.

## 이 작업에서 같이 바꾼 설정
- **`daily.nightRecovery` 18 → 14**: 하룻밤 피로 회복.
  - 18에서는 어떤 루틴으로도 피로가 70(부상 72)에 닿지 않았다. 시즌 내내 부상 0회, 피로는 3~5.
  - 피로 경고·부상·"피로 위험" 표시가 의미가 없었고, 성장 집중형이 부상을 더 겪게 만들 방법도 없었다.
  - 10까지 낮추면 성장 집중형 부상이 1.5회가 되지만, 스크림 많은 기본 루틴이 시즌 10회 부상이라 너무 가혹해서 14로 정했다.
- **경기력(파워) 보정 `match.userPerf`**: `match.js`에 하드코딩돼 있던 계수를 config로 옮기고 영향을 키웠다.
  - 처음 값(컨디션 0.06·기준 70, 피로 0.05, 멘탈 0.03)에서는 좋은 상태와 나쁜 상태의 평점 차가 0.6밖에 안 됐다.
  - 컨디션 0.12·기준 80, 피로 0.1, 멘탈 0.05로 올렸다. 기준을 80으로 올려서 푹 쉰 선수가 덤으로 세지지는 않는다.
- **`daily.legacyFatigue`**: `sim-career.mjs`의 "예전 3칸 vs 하루 1개 ±10%" 비교(`--advisor` 없이)는 활동 효과 보정만 보는 도구라 예전 피로 기준(밤 회복 18, 컨디션 보정 옛 값)으로 돌린다.
  - 피로가 실제로 영향을 주게 바꾼 뒤에는 스크림 많은 시험 루틴이 부상(시즌 4~9회)과 낮은 컨디션 때문에 비교가 틀어졌다.
  - 곱셈 배율(`ACTIVITY_DAY_MULTIPLIER`)을 3.2~3.6으로 올려 봤지만 부상만 늘고 맞지 않아서 3.0을 유지했다.
  - 피로·부상 쪽은 `--advisor` 모드가 지금 설정 그대로 본다.
- **경기 순서**: `simulateMatch`(경기를 화면 없이 처리)도 내 선수가 뛰면 컨디션·멘탈·피로를 반영한다. 직접 진행하는 경기와 같은 식이다.

### 읽는 법과 한계
- **성장 집중형의 부상은 시즌 0.75회로 많지 않다.** 피로·부상 쪽은 게임이 원래 느슨했고(밤 회복 18), 14로 낮춘 값에서도 합리적으로 짜인 안은 72까지 잘 가지 않는다. 대신 피로 최고 70대에 닿아 카드에 위험을 표시한다.
- **평점 표준편차는 목표로 삼지 않았다.** 시즌 실경기 표준편차는 균형형 1.83, 성장 집중형 1.67, 컨디션 관리형 1.73이다. 오차(±0.08)보다 작은 차이고, 같은 경기 시드로 계획별 컨디션 분포만 바꿔 다시 돌려도 균형형 1.46, 성장 집중형 1.51, 컨디션 관리형 1.59로 순서가 맞지 않았다. 상태가 나쁘면 평점이 낮은 쪽에 몰려 표준편차가 줄기 때문이다. 대신 컨디션·피로·멘탈이 파워에 주는 영향의 표준편차(경기 운 없이 계산)와 나쁜 경기 비율로 본다.
- **균형형과 컨디션 관리형은 경기 당일 상태가 거의 같다** (컨디션 91 vs 93). 경기 전날 푹 쉬면 둘 다 피로가 0에 가까워지기 때문이다. 차이는 경기 없는 날의 훈련량(OVR 77.2 vs 74.0)에서 난다.
- **콜업은 기본 루틴보다 빠르다** (46~68일 vs 109일). 주 상황마다 감독 신뢰·스크림 점수(콜업 게이지)를 가치에 넣었기 때문이다.
- 시드 8개라 OVR 같은 평균도 ±0.3 정도는 흔들린다. 계획 사이 순서(성장 집중 > 균형 > 컨디션)는 시드 6~8개로 여러 번 돌려도 같았다.

### 이전 설정과의 비교 (`legacyFatigue` 기준 `sim-career.mjs` 예전 vs 새)
- 능력치 성장 +3.8% ✓, 피로 누적 −8.7% ✓, 수입 −10.6% (목표 ±10%에서 0.6%p 벗어남).
- 수입은 콜업 시점에 따라 월급이 달라져 시드마다 흔들린다 (예전 62일, 새 90일 콜업).
