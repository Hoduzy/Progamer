# 버그 신고 파일

경기 화면 오른쪽의 **🐞 버그 신고** 버튼을 누르면 `bug-<시드>-<분초>.json` 파일이 다운로드됩니다.
그 파일을 이 폴더에 넣고 알려 주세요.

파일 내용:
- `seed`, `gameT`: 경기 시드와 신고 시각
- `input`: 경기 생성 입력 (양 팀 선수·챔피언·패치) — 그대로 다시 만들 수 있음
- `choices`: 지금까지 내 선택 장면 기록 (시각, 장면, 고른 선택지)
- `recent`: 최근 30초(7틱) 선수 위치·체력·임무
- `events`: 최근 30초 이벤트 로그
- `plans`, `objectives`, `waves`, `structures`: 신고 시점 팀 계획·오브젝트·웨이브·구조물 상태

재현:
```
node tools/replay-bug.mjs bug-reports/bug-XXXX.json
```
같은 장면을 그대로 다시 돌려 신고 시점 상태가 일치하는지 확인하고, 정합성 검사 결과와 직전 30초 타임라인을 출력합니다.
